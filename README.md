# Day's Kitchen

Prospect demo for Day's Kitchen, a Filipino café and catering shop in Scarborough, built by ClaudAura IT Solutions.

## Run

```bash
npm install
npm run dev
```

`npm run build` produces a Next.js app that deploys on Vercel with no environment variables.

## What is on the page

Public facts only: Instagram profile and recent posts, the Linktree, the 2025 private event package, the Uber Eats menu for the Tapscott store, and Google Maps and Yelp listings. Hours and prices are labeled with where they came from.
